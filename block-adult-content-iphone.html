How to block adult content on iPhone

Three ways to do it, from what's already on the phone to what actually holds. Each one has a real limit — we'd rather you know it now than find it later.

01Screen Time content restrictions

Free, and it's already on the phone. Go to Settings → Screen Time → Content & Privacy Restrictions → Content Restrictions → Web Content, then choose Limit Adult Websites. Apple's filter blocks known adult sites automatically and lets you add your own sites to Always Allow or Never Allow. Turn on Content & Privacy Restrictions first and set a Screen Time passcode, or the setting can simply be switched back off.

For younger kids, Allowed Websites Only is stricter — the phone only opens a list you set.

Where this stops. The filter works in Safari, and in other browsers that hook into the same system content filter. It doesn't reach inside individual apps — a browser built for privacy, an in-app browser, or content shared through social and chat apps can fall outside it. And the passcode that locks these settings resets with the Apple ID password: go to Settings → Screen Time → Change Screen Time Passcode → Forgot Passcode, and Apple ID sign-in takes over. Apple sets this up as a recovery path for parents, not a hole — but it means the Screen Time passcode is only ever as private as your Apple ID password. Keep that one to yourself.

02DNS profiles and family DNS

Also free. A DNS profile points the phone's web requests through a filtering DNS service — several offer free tiers built for families — and blocks adult sites at the domain level before they load. Install it as a configuration profile: Settings → General → VPN & Device Management, or through the DNS provider's own app.

Where this stops. A DNS profile only filters the network it's active on — if it's a router-level setup, it stops working the moment the phone leaves Wi-Fi for mobile data. And a profile installed as a normal configuration profile can be removed from the same VPN & Device Management screen it was installed from, with no passcode needed unless Content & Privacy Restrictions is separately locked down to block profile removal.

FAQ

Questions, answered.

Does Screen Time block adult content inside apps, not just Safari?

Only partly. Limit Adult Websites is a web filter — it works in Safari and other apps that use the same system filter. It doesn't reach content shared through social apps, chat apps, or an in-app browser that doesn't hook into it.

My child knows our Apple ID password — does any of this still work?

Not the parts that rely on the Screen Time passcode — that includes Screen Time restrictions and Zaksha's iPhone lock, since both pin themselves on the same way. A DNS profile doesn't depend on the Apple ID at all, but it's removable from Settings with no password. If the Apple ID password is shared, changing it is the actual fix, not switching filtering methods.

Can I use a DNS profile and Zaksha together?

You can, but there's little point — Zaksha's on-device filtering already covers what a DNS profile does, on Wi-Fi and mobile data both, so a second DNS layer just adds a second thing to maintain.

Can my child bypass Zaksha on iPhone?

It's tamper-resistant, not unbreakable. Zaksha is pinned on with Screen Time, so it's hard for a child to switch off or remove, and doing so locks their apps and pages you immediately. But the Apple ID password can still reset the Screen Time passcode behind it, on any iPhone, for any app built this way. Keep that password to yourself and the setup holds.
