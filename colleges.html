What you get

Filtering for the labs you run.

Lab-hour schedules

Set the hours a lab is filtered. Social media, gaming, streaming and AI chatbots can be blocked for a test morning and back to normal in the afternoon.

Category blocks

Adult content, gambling, torrents, gaming, social media and streaming are one switch each. Add your own domains to block.

Per-device reports

See the domains each lab machine asked for and whether they were blocked, per device. Reports can be exported.

Alerts when a machine goes quiet

If a lab PC stops reporting, the console flags it so you can check it before the next session.

Where labs use it

Three common sessions.

Routine tests

Block the distractions you choose in the lab for the length of a test, on a schedule that repeats weekly.

Placement drives

Block the categories you choose on lab machines during the online rounds a visiting recruiter runs.

Interview rounds

Block social media and chat sites on the interview-room PCs while a round is on.

What it is not

Zaksha blocks the categories and sites you choose. It is not a locked-down exam browser, and it does not limit a machine to a fixed list of sites.

How setup works

From a lab full of PCs to filtered.

1

Create your account

We set up your console. You get an enrollment key for your labs.

2

Install on the lab PCs

Download the bulk installer pack for Windows and run it on each lab machine. Each PC shows up in the console as it enrols.

3

Set rules and hours

Group the PCs by lab, switch on the categories you want blocked and set the lab-hour schedule.

Campus-wide Wi-Fi filtering

We can also run a dedicated instance that your campus DNS points at, so traffic on the campus Wi-Fi is filtered too. Talk to us if you want it. One limit applies: a VPN or a browser's own encrypted DNS setting gets around network filtering.
