What you get

Rules for every laptop, one console.

Company-wide rules

Block categories such as adult content, gambling, gaming, social media and streaming, and add your own domains to the list.

Per-device reports

See which domains each laptop asked for and whether they were blocked. Reports can be exported.

Gone-quiet alerts

When a laptop stops reporting, the console flags it so you can find out why.

Work-hour rules, set once.

Put laptops in groups and give each group its own categories and schedule. In the example, marketing can reach social media during work hours while accounts is blocked all day.

Staying on

Built to stay on.

The agent is a Windows system service. A standard user account can't stop it, and removing it takes the admin password.

The limit

Someone with the admin password, or who wipes and reinstalls Windows, can still remove it. If a user's own account is an administrator, the agent falls back to alerting you instead of blocking removal. Give employees standard accounts.
